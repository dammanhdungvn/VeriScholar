\subsection{Dịch vụ suy luận OpenAI API và hạ tầng Microsoft Azure}
\label{subsec:azure_openai_compat}
Dịch vụ suy luận OpenAI API trên nền tảng đám mây Microsoft Azure cung cấp giao diện lập trình tiêu chuẩn để truy cập mô hình suy luận \texttt{gpt-4o-mini} và mô hình biểu diễn véc-tơ ngữ nghĩa hiện đại.

\subsection{Môi trường hộp cát an toàn E2B MicroVM}
\label{subsec:e2b_sandbox_compat}
E2B Sandbox dựa trên công nghệ ảo hóa siêu nhỏ AWS Firecracker \cite{agache2020firecracker}, khởi tạo trong 200ms với khả năng cô lập ranh giới hạt nhân ngăn chặn tấn công thực thi mã từ xa.

\subsection{Mô hình bảo mật khóa cá nhân BYOK AES-256-GCM}
\label{subsec:byok_security_compat}
Chuẩn mã hóa đối xứng xác thực AEAD với thuật toán AES-256 ở chế độ GCM \cite{dworkin2007}:
\begin{equation}
\label{eq:aes_gcm_compat}
\begin{aligned}
C &= \text{GCTR}_K\bigl(\text{inc}_{32}(J_0), \text{Plaintext}\bigr), \quad J_0 = \text{IV} \parallel 0^{31} \parallel 1 \\
T &= \text{GHASH}_H(\text{AAD}, C) \oplus E_K(J_0)
\end{aligned}
\end{equation}
Khóa API được giải mã tạm thời trong bộ nhớ khả biến và không bao giờ lưu vết trên đĩa.
