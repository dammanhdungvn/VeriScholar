\section{Môi trường cài đặt và triển khai hệ thống}
\label{sec:moi_truong}
\subsection{Cấu hình môi trường phần cứng và phần mềm}
\label{subsec:cau_hinh_moi_truong}
Hệ thống \VS\ được cài đặt và kiểm nghiệm thực tế trên môi trường máy chủ đám mây Azure Ubuntu 24.04 LTS (x86\_64, 4 vCPU, 16GB RAM) với các phần mềm nền tảng:
\begin{itemize}
    \item \textbf{Hệ quản trị cơ sở dữ liệu:} PostgreSQL 16.2 kết hợp tiện ích mở rộng \texttt{pgvector} v0.7.0.
    \item \textbf{Môi trường thực thi Backend:} Python 3.12, trình quản lý gói siêu tốc \texttt{uv}, FastAPI và SQLAlchemy 2.0 Async.
    \item \textbf{Môi trường thực thi Frontend:} Node.js 22, React 19, Tailwind CSS, Zustand và Vite.
    \item \textbf{Môi trường thực thi hộp cát đám mây:} E2B Sandbox MicroVM phục vụ chu trình tự sửa lỗi biên dịch \LaTeX.
    \item \textbf{Nền tảng quan sát và giám sát LLM:} Langfuse Cloud (Project ID: \texttt{cmv8ub9jl00nvad0je39ueywo}).
\end{itemize}

\subsection{Tổ chức kho mã nguồn Monorepo}
\label{subsec:monorepo}
Kho mã nguồn được cấu trúc theo mô hình Monorepo chặt chẽ gồm ba không gian chính: \texttt{packages/core} (lõi miền nghiệp vụ thuần khiết, không phụ thuộc I/O), \texttt{apps/api} (tầng dịch vụ web FastAPI cung cấp RESTful API và SSE) và \texttt{apps/web} (giao diện người dùng React 19).

\section{Giao diện các phân hệ chính của VeriScholar}
\label{sec:giao_dien}
\subsection{Phân hệ Khám phá tài liệu khoa học}
\label{subsec:ui_discovery}
Giao diện phân hệ Khám phá cho phép học giả tìm kiếm đồng thời qua Exa AI, arXiv và Semantic Scholar, hiển thị kết quả phân loại rõ ràng giữa bài có tệp PDF mở (\textit{Open Access}) và bài báo thu phí, hỗ trợ nạp bài tức thì vào thư viện nghiên cứu cá nhân.

\subsection{Phân hệ Đọc sâu và Tô sáng tọa độ Bounding Box}
\label{subsec:ui_deep_reading}
Giao diện đọc sâu gồm hai khung hiển thị song song: khung đọc bản PDF gốc bên trái và khung trò chuyện thông minh bên phải. Khi AI trích dẫn câu trả lời, trình duyệt tự động nhảy tới đúng trang tài liệu và vẽ khung viền vàng định vị chính xác vị trí đoạn văn gốc trong vòng 1 giây.

\subsection{Phân hệ Hồ sơ học giả và Két sắt khóa cá nhân}
\label{subsec:ui_profile}
Giao diện quản lý hồ sơ học giả (\texttt{UserProfileModal} và \texttt{ScholarSettingsView}) cho phép liên kết mã định danh học giả ORCID iD 16 chữ số, cấu hình tùy chọn mô hình ngôn ngữ và mã hóa lưu trữ khóa API OpenAI cá nhân (BYOK) bằng thuật toán AES-256-GCM.

\section{Kết quả kiểm thử tự động hệ thống qua 4 Cổng xác minh}
\label{sec:kiem_thu_4_gate}
\subsection{Quy trình kiểm thử 4 Cổng bắt buộc}
\label{subsec:quy_trinh_gate}
Nhằm đảm bảo chất lượng phần mềm không bao giờ bị suy giảm và tuân thủ tuyệt đối quy tắc vận hành, hệ thống tích hợp chu trình kiểm thử tự động 4 Cổng qua kịch bản kiểm thử:
\begin{itemize}
    \item \textbf{Cổng 1 (Linter \& Formatter Python):} Kiểm tra toàn vẹn định dạng và lỗi cú pháp tĩnh qua \texttt{uv run ruff check .} và \texttt{uv run ruff format --check .}.
    \item \textbf{Cổng 2 (Backend \& Domain Tests):} Chạy toàn bộ 54 bài kiểm thử đơn vị và tích hợp \texttt{pytest} bao phủ toàn diện ranh giới kiến trúc lục giác, mô hình CSDL và tài liệu báo cáo.
    \item \textbf{Cổng 3 (Frontend Unit Tests):} Kiểm thử các thành phần giao diện người dùng qua \texttt{npm --prefix apps/web run test}.
    \item \textbf{Cổng 4 (Production Build):} Kiểm tra quy trình đóng gói bản dựng thương mại qua \texttt{npm --prefix apps/web run build}.
\end{itemize}
