\noindent \textbf{2. Mục tiêu của ĐATN}
\vspace{0.02cm}

\noindent \textbf{Mục tiêu tổng quát:}
\begin{itemize}[leftmargin=*, noitemsep, topsep=1pt, parsep=0pt, partopsep=0pt]
    \item Xây dựng nền tảng Trợ lý AI nghiên cứu khoa học VeriScholar cho học giả VinUni.
    \item Triệt tiêu ảo giác qua Hybrid RAG và kiểm chứng trích dẫn Bounding Box hai tầng.
    \item Tự động hóa biên dịch LaTeX trong sandbox E2B và bảo mật khóa riêng BYOK.
\end{itemize}

\vspace{0.05cm}
\noindent \textbf{Mục tiêu cụ thể:}
\begin{itemize}[leftmargin=*, noitemsep, topsep=1pt, parsep=0pt, partopsep=0pt]
    \item[\textbf{--}] \textbf{Về sản phẩm:}
    \begin{itemize}[leftmargin=*, noitemsep, topsep=1pt, parsep=0pt, partopsep=0pt]
        \item Phân hệ Khám phá: Tìm kiếm học thuật đa nguồn (arXiv, Semantic Scholar, CrossRef) và lưu trữ CAS SHA-256.
        \item Phân hệ Đọc sâu: Đọc PDF Canvas hai cột kết hợp kiểm chứng tọa độ Bounding Box.
        \item Phân hệ GraphRAG: Đồ thị tri thức 4 thực thể (Paper, Method, Dataset, MetricResult).
        \item Phân hệ Soạn thảo: Soạn thảo LaTeX trực tuyến, tự sửa lỗi trong sandbox E2B.
        \item Phân hệ Bảo mật: Quản lý kho khóa API cá nhân BYOK mã hóa AES-256-GCM.
    \end{itemize}
    \vspace{0.02cm}
    \item[\textbf{--}] \textbf{Về kiến thức và kỹ năng:}
    \begin{itemize}[leftmargin=*, noitemsep, topsep=1pt, parsep=0pt, partopsep=0pt]
        \item Vận dụng kiến thức: Kỹ nghệ phần mềm, CSDL nâng cao, Kiến trúc hệ thống, NLP.
        \item Nắm vững quy trình phát triển phần mềm theo phương pháp kiểm thử TDD.
        \item Làm chủ kỹ thuật Hybrid RAG, đồ thị tri thức GraphRAG và tác nhân ReAct tự chủ.
        \item Rèn luyện năng lực nghiên cứu độc lập và tuân thủ liêm chính học thuật.
    \end{itemize}
\end{itemize}

\noindent \textbf{3. Các nhiệm vụ cụ thể của ĐATN}
\vspace{0.02cm}

\noindent Để hoàn thành các mục tiêu đề ra, sinh viên thực hiện các nhiệm vụ cụ thể sau:
\begin{itemize}[leftmargin=*, noitemsep, topsep=1.5pt, parsep=0pt, partopsep=0pt]
    \item[--] Khảo sát quy trình nghiên cứu, viết bài báo tại VinUni; xác định bài toán liêm chính học thuật.
    \item[--] Đặc tả yêu cầu chức năng và phi chức năng hệ thống (BYOK, trễ RAG $\le 1{,}5\,\text{s}$, $\text{IoU} \ge 0{,}85$).
    \item[--] Thiết kế kiến trúc Lục giác, mô hình CSDL quan hệ PostgreSQL kết hợp véc-tơ pgvector.
    \item[--] Cài đặt hệ thống Backend (FastAPI, pgvector, LangGraph) và Frontend (TypeScript, React 19).
    \item[--] Tích hợp sandbox E2B MicroVM biên dịch LaTeX cô lập an toàn, ngăn chặn mã độc hại.
    \item[--] Triển khai toàn bộ quy trình kiểm thử TDD với 580 kịch bản kiểm thử tự động (340 Backend pytest và 240 Frontend vitest, 100\% pass).
    \item[--] Đánh giá thực nghiệm hệ thống trên các bài báo thực tế, đo độ trễ và độ chính xác tọa độ.
    \item[--] Viết báo cáo tổng kết đồ án tốt nghiệp, chuẩn bị slide thuyết trình và đóng gói sản phẩm.
\end{itemize}
